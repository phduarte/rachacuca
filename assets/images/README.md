# Imagens do jogo

As 12 imagens originais do jogo ficam em `public/images/originals/` (geradas por
`scripts/make-originals.py`). Licenças de todas as imagens: [LICENSES.md](LICENSES.md).

Toda imagem colocada nesta pasta (`.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`, `.avif`)
aparece no menu **IMAGEM** do jogo, depois das imagens desenhadas em código.

- O nome na tela vem do nome do arquivo: `ze-do-cafe.png` vira **ZE DO CAFE**.
- Imagens que não são quadradas são recortadas no centro.
- Prefira imagens de até 1024 × 1024: elas entram no pacote do app e no cache offline.
- Arte pixelada (até 128 × 128) é exibida sem suavização.
- Só coloque aqui imagens com direito de uso (seção 4.1 de [docs/SPECS.md](../../docs/SPECS.md)).
  Registre a origem e a licença de cada uma em `LICENSES.md`, nesta pasta.
